  `ChinaTextbook-index/posters/`, replacing only `.pdf` with `.png`.
- The index is hierarchical: `ChinaTextbook-index/index.json` contains only
  top-level directory nodes. Nested indexes are stored beside their matching
  posters under `ChinaTextbook-index/posters/`, so a source directory such as
  `小学/数学/人教版` maps to
  `ChinaTextbook-index/posters/小学/数学/人教版/index.json`. A directory index
  contains child-directory references and only the books directly inside that
  directory. Pages can therefore load indexes lazily as users expand the tree.
- Leaf book records expose `stage`, `subject`, `edition`, `grade`, and the full
  `directoryParts` array alongside each book's source path.
- One source PDF has a damaged XRef/pages structure and needs repair before
  its poster can be extracted; it remains listed in `index.json`.
- This file intentionally stops at the subject/version level. Individual PDF
  names are represented by the generated hierarchical JSON indexes, not copied
  here.

Important file layout
- A book may be stored as one PDF: `book.pdf`
- Large books may be split into sibling parts: `book.pdf.1`, `book.pdf.2`, ...
- Split parts belong to one logical book and must be grouped into one index
  entry, one download item, and one poster.
- The poster normally uses the first page of the logical book. Split parts do
  not get separate posters.
- The original project provides a PDF merge tool for reassembling split books:
  https://github.com/TapXWorld/ChinaTextbook-tools/releases
- The index must retain the ordered part list and explain that users should
  merge the parts with the original tool before reading the book.
- The source repository also contains one `.djvu`, one `.md`, one `.exe`, and
  other non-PDF files; these need an explicit policy before indexing.
